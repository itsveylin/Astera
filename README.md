# Astera 💎

Astera is a modern personal finance management platform designed to help users take control of their financial life through intelligent tracking, budgeting, goal planning, and investment monitoring.

The application provides a centralized dashboard where users can manage transactions, monitor spending patterns, track subscriptions, set savings goals, and analyze their financial health through interactive insights and reports.

---

## 🚀 Features

### Financial Management

* Transaction Tracking
* Expense Categorization
* Recurring Expense Management
* Credit Card Tracking
* Subscription Monitoring
